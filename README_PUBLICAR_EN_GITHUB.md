# Publicar Código Gripsholm para móvil

## 1. Crear el repositorio

En GitHub, crea un repositorio nuevo llamado, por ejemplo, `codigo-gripsholm`. Debe ser público para usar GitHub Pages sin configuración adicional.

## 2. Subir esta carpeta completa

Sube **todo el contenido** de esta carpeta, incluidos `assets`, los archivos `dia0.html` a `dia10.html`, `index.html`, `manifest.webmanifest` y `service-worker.js`.

No subas la carpeta contenedora `V_8_Codigo_Gripsholm`: abre la carpeta y sube lo que hay dentro.

## 3. Activar GitHub Pages

En el repositorio, abre **Settings → Pages**.

- En **Build and deployment**, elige **Deploy from a branch**.
- Selecciona la rama `main`.
- Selecciona la carpeta `/(root)`.
- Pulsa **Save**.

GitHub mostrará una dirección parecida a:

`https://TU-USUARIO.github.io/codigo-gripsholm/`

## 4. Instalarla en un móvil

Abre esa dirección una vez con internet.

- **Android (Chrome):** menú ⋮ → **Instalar aplicación**.
- **iPhone (Safari):** Compartir → **Añadir a pantalla de inicio**.

Después aparecerá el icono de Código Gripsholm en el móvil. La primera descarga guarda los diez días y sus imágenes para poder abrirlos sin cobertura.

## Importante

- Espera a que la primera carga termine antes de cerrar el navegador.
- Si publicas una versión nueva, abre de nuevo la app con conexión y recárgala una vez: la actualización se descargará automáticamente.
